# MSITM6341 Python Group A Final - Telco Churn Prediction App

React + Flask + ML pipelines + AI suggestions.

## Setup
- Backend: `cd backend && pip install -r requirements.txt && python ml/train.py && python app.py`
- Frontend: `cd frontend && npm install && npm run dev`
- Copy `.env.example` to `.env` and set `AI_API_KEY`.
